本文件夹包含：
1.main.html：本作品的主页面，双击用浏览器即可打开
2.script1.html，.script2.html，.script3.html：3个科考推理学习页面代码
3.video1.html，video2.html，video3.html，video4.html，video5.html:5个分视频模块页面代码
4.chat.js：悬浮智能地理助手的相关代码
5.picture文件夹：包含网页中所需相关图片，用作背景图、视频封面、剧本封面
6.video文件夹：包含6个微课视频，其中video为微课主视频，video1-video5为5个微课模块分视频

*网页的打开方式：双击main.html用浏览器打开即可
